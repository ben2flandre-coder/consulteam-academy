# Lot de prompts GPT — A260E2A (14/11/2026)

64 prompts, un par image. Copier le bloc « Prompt » dans GPT, une image par requête.

## Règles

- Un prompt = une image indépendante.
- Aucun logo, aucune marque, aucun texte lisible dans les images (les textes sont ajoutés en HTML).
- Compositions originales ; aucune reproduction d'affiche, de brochure, de pictogramme ou de logo existant.
- Distances, tensions, classes de gants et ordres de séquence ne figurent jamais dans les images : ils sont donnés par les schémas SVG et le texte, sources à l'appui.
- Chaque image est relue (anatomie, matériel, cohérence technique) avant publication ; le niveau « renforcé » exige une relecture par un formateur habilité.
- Registre : prompt, sha256, date, relecteur ; les images générées sont signalées comme telles.
- Visuels officiels du réseau de formation : fournis par le formateur et intégrés sans modification, hors de ce lot.

## Convention de nommage

Fichier `images/<ID>.webp` ; renseigner sha256, relecteur et date dans `suivi-visuels-A260E2A.csv`.
